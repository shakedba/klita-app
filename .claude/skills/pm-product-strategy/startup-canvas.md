# Startup Canvas

A strategic planning tool that integrates product strategy with business model design. Created specifically for launching new products and evaluating startup concepts.

## Why Startup Canvas Over Alternatives

| Framework | Best For | Limitation |
|-----------|---------|------------|
| Business Model Canvas | Established businesses, investors | Mixes strategy with operations; no vision or trade-offs |
| Lean Canvas | Fast brainstorming | Redundancy between sections; lacks strategic coherence |
| **Startup Canvas** | **New products** | Separates strategy from business model |

## Structure

### Part 1: Product Strategy (9 Sections)

Apply **product-strategy** skill:

1. Vision
2. Market Segments
3. Relative Costs
4. Value Proposition
5. Trade-offs (Can't / Won't)
6. Key Metrics
7. Growth
8. Capabilities
9. Defensibility

### Part 2: Business Model

10. **Cost Structure**: Fixed costs, variable costs, economies of scale
11. **Revenue Streams**: How each segment pays, pricing model, unit economics

## Output Format

```
## Startup Canvas: [Product]

### Part 1: Product Strategy

| Section | Content |
|---------|--------|
| Vision | [one sentence] |
| Market Segments | [segments with JTBD] |
| Relative Costs | [cost position] |
| Value Proposition | [before/how/after per segment] |
| Trade-offs | Can't: [...] / Won't: [...] |
| Key Metrics | North Star: [metric] |
| Growth | [acquisition + unit economics] |
| Capabilities | [required + build/partner/buy] |
| Defensibility | [moat type] |

### Part 2: Business Model

| Block | Content |
|-------|--------|
| Cost Structure | [fixed costs, variable costs, scale economics] |
| Revenue Streams | [model, pricing, LTV, CAC, payback] |

### Coherence Check
[Do all 11 sections reinforce each other? Where are the tensions?]

### Critical Hypotheses
[Top 3-5 assumptions that must be validated]

### Validation Plan
[Low-effort experiments to test key assumptions]
```

## Key Insight

"Your competitors can't or won't copy the integrated set of choices." Defensibility emerges from how all strategic elements reinforce each other, not from any single advantage.
