# Value Proposition

A 6-part JTBD-based template for crafting customer-centric value propositions. Starts with the customer, not the product.

## The 6-Part Template

1. **Who** — Target customer segment and their characteristics
   - Demographics, firmographics, behaviors
   - What role do they play? What are they responsible for?

2. **Why** — Core problem and desired outcomes
   - The job they're trying to do (JTBD)
   - The outcome they want to achieve
   - Why this matters to them

3. **What Before** — Current painful reality
   - Existing tools and workarounds
   - Friction, frustrations, limitations
   - What does the struggle look like today?

4. **How** — Your solution
   - Specific features and capabilities that deliver value
   - How you solve the problem differently
   - The mechanism of value delivery

5. **What After** — The improved outcome
   - What becomes possible?
   - Quantified improvement where possible
   - Emotional and functional outcomes

6. **Alternatives** — Competing solutions
   - What they'd use without you
   - Why you're better (specific, not generic)
   - Switching factors

## Output Format

```
## Value Proposition: [Product]

### For [Segment]:

1. **Who**: [profile]
2. **Why**: [JTBD and desired outcome]
3. **What Before**: [current pain and workarounds]
4. **How**: [solution and key capabilities]
5. **What After**: [improved outcome, quantified if possible]
6. **Alternatives**: [competitors and why you win]

### Value Proposition Statement
For [who] who [need/want], [product] is a [category] that [key benefit].
Unlike [primary alternative], [product] [key differentiator].

### Reusable Statements
- **Marketing**: [...]
- **Sales**: [...]
- **Onboarding**: [...]
```

## Key Distinctions

- This template starts with the customer (Who/Why) and works toward the solution — unlike Strategyzer's Value Proposition Canvas which leads with the product
- Explicitly addresses alternatives, which most frameworks omit
- Each segment gets its own value proposition — don't try to write one for everyone
- Test with real customers before finalizing

## Key Insight

"Value propositions are segment-specific. Different customer groups have different jobs, different pain points, and different alternatives — they deserve different value props."
