# Monetization Strategy

Develop 3–5 distinct monetization approaches, evaluating each through audience alignment, financial projections, competitive positioning, and validation experiments.

## Common Revenue Models

| Model | Conversion | Best For |
|-------|-----------|----------|
| Freemium | 1–5% typical | Products with network effects |
| Subscription | Recurring MRR | Ongoing value delivery |
| Usage-based | Variable | Infrastructure, APIs |
| Seat-based | Per-user | Team/enterprise tools |
| One-time purchase | Upfront | Permanent license |
| Marketplace fees | % of transaction | Two-sided platforms |
| Advertising | CPM/CPC | High-volume consumer |

## Evaluation Framework

For each candidate model assess:

1. **Strategy Mechanics**: How does this revenue model work for this specific product?
2. **Audience Alignment**: Which customer segments does it serve? Willingness to pay?
3. **Financial Modeling**: CAC, LTV, gross margin, break-even timeline
4. **Risk Assessment**: Adoption barriers, churn factors, implementation complexity
5. **Validation Testing**: Low-cost experiments to confirm customer demand

## Key Insight

Most products use hybrid models (e.g., freemium + upgrade, subscription + marketplace fees). Validate pricing assumptions early through customer conversations before full implementation.
