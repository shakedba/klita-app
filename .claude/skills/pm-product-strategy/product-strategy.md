# Product Strategy Canvas

A 9-section framework for defining how a product will compete, win, and grow in the market. Ensures all strategic elements are coherent and mutually reinforcing.

## The Nine Sections

1. **Vision**
   - Inspiring north star and core purpose
   - Why does this product exist?
   - "We believe..."

2. **Market Segments**
   - Target customers defined by Jobs to Be Done
   - Primary vs. secondary segments
   - Size and addressability

3. **Relative Costs**
   - Cost leadership vs. premium positioning
   - What drives your cost structure vs. competitors?

4. **Value Proposition**
   - Before/How/After narrative for each segment
   - What changes for customers because of this product?

5. **Trade-offs**
   - Explicit scope limitations that create focus
   - What you deliberately will NOT do
   - "Can't and Won't"

6. **Key Metrics**
   - North Star metric
   - Quarterly priority metrics
   - Leading indicators

7. **Growth**
   - Acquisition strategy and channels
   - Unit economics: CAC, LTV, payback period
   - Growth loops

8. **Capabilities**
   - Required competencies and resources
   - Build vs. partner vs. buy decisions

9. **Defensibility**
   - Competitive moat
   - Barriers to imitation
   - Network effects, switching costs, data advantages

## Output Format

```
## Product Strategy Canvas: [Product]

**Date**: [today] | **Stage**: [idea/early/growth/mature]

### Vision
[One inspiring sentence]

### Market Segments
| Segment | JTBD | Size | Priority |
|---------|------|------|----------|

### Value Proposition
| Segment | Before | How | After |
|---------|--------|-----|-------|

### Trade-offs
We WILL: [explicit choices]
We WON'T: [explicit exclusions]

### Key Metrics
- North Star: [metric and current baseline]
- Q[X] priorities: [metrics]

### Growth Engine
[Acquisition strategy + unit economics]

### Core Capabilities
[Required + build/partner/buy decisions]

### Defensibility
[Moat type + current strength + how to build it]

### Critical Hypotheses
[Assumptions that must be true for strategy to work + validation plan]
```

## Key Principle

"Competitors can't or won't copy the integrated set of choices." Defensibility comes from how all elements reinforce each other, not from isolated advantages.
