# Becoming More Strategic

This skill helps product managers shift from tactical execution to strategic thinking using frameworks by Anneka Gupta.

## Key Concepts

**Core Distinction:**
Strategic work focuses on the "why" and long-term vision, while tactical work handles the "what" and near-term execution.

**Time Horizon Framework:**
- NOW (0-3 months): Current quarter execution
- NEXT (3-12 months): Strategic building blocks
- LATER (12+ months): Positioning and vision

## Practical Application

The strategic framing template guides you through articulating both the tactical details and strategic rationale. It emphasizes connecting features to user problems, business impact, and company objectives.

**Central Principle:**
As Gupta notes, "Strategic PMs start with why. Tactical PMs start with what." The distinction matters because it shapes how you prioritize, communicate, and measure success.

## Essential Checklist

- [ ] Begin with purpose (why)
- [ ] Connect to business goals
- [ ] Use time horizons (now/next/later)
- [ ] Communicate the problem first
- [ ] Tie solution to strategy
- [ ] Demonstrate business impact alongside vision
