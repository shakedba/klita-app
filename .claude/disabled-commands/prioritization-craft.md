# Prioritization Engine

This skill applies key frameworks for making smart product decisions.

## RICE Framework

Calculates priority scores using the formula:

Score = (Reach x Impact x Confidence) / Effort

- **Reach**: Users affected per quarter
- **Impact**: Range from 0.25 (minimal) to 3 (massive)
- **Confidence**: Certainty level (%)
- **Effort**: Person-months required

## Value vs Effort Matrix

| | Low Effort | High Effort |
|---|---|---|
| **High Value** | Quick Wins (do first) | Strategic Projects (plan for) |
| **Low Value** | Fill-ins (do later) | Money Pits (reject) |

## Key Principle

"Without prioritization, everything feels urgent" and prevents quality execution. Saying no to lower-scoring opportunities is "the most underrated PM skill."

## When to Use

- Feature requests
- Backlog management
- Tradeoff analysis
- Communicating rejections

## Action Template

For each candidate, score across:
1. Reach (users/quarter)
2. Impact (0.25-3)
3. Confidence (%)
4. Effort (person-months)

Then order by RICE score to guide allocation decisions.
