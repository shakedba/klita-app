# Decision Architecture Framework

This skill helps navigate tough choices using probabilistic thinking and structured decision-making approaches.

## Core Methods

**Expected Value Analysis** calculates potential outcomes by multiplying success probability by gains, then subtracting failure probability times costs. For instance, a 70% chance of $100K gain minus a 30% chance of $20K loss yields $64K in expected value.

**Regret Minimization** applies future-focused thinking: imagining yourself at 80 and asking whether you would regret not attempting something now. This combats short-term bias.

## Decision Matrix Template

Structure choices by:
- Computing expected values for each option
- Assessing long-term regret potential
- Evaluating whether decisions can be undone (reversibility)
- Running pre-mortems to identify failure points

## Key Principles

Annie Duke notes: "Life is poker, not chess. We're making decisions with incomplete information."

Jeff Bezos suggests: "Most decisions should probably be made with somewhere around 70% of the information you wish you had."

This acknowledges that perfect certainty rarely exists - the goal is making informed choices despite uncertainty using structured analysis rather than paralysis by analysis.
