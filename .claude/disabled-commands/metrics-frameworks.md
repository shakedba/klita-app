# Metrics That Matter

## Overview
This skill teaches how to define meaningful metrics using established frameworks like North Star and AARRR, helping distinguish between vanity metrics and actionable ones for product success.

## Core Frameworks

**North Star Metric** represents the single metric capturing your core customer value. Strong North Stars:
- Measure actual value delivery
- Serve as leading revenue indicators
- Align with product vision
- Enable team action

Examples: Airbnb's nights booked, Slack's messages sent.

**AARRR Framework** organizes metrics across five stages:
- **Acquisition** - How users discover you
- **Activation** - Initial value experience
- **Retention** - Returning users
- **Revenue** - Monetization
- **Referral** - Viral growth

## Dashboard Template

Build a comprehensive metrics dashboard by:
1. Establishing your North Star metric
2. Populating supporting metrics across all five AARRR categories
3. Setting current values and targets for each

## Implementation Checklist

- [ ] North Star metric defined
- [ ] AARRR stages covered
- [ ] Leading indicators identified (predict outcomes)
- [ ] Lagging indicators identified (measure results)
- [ ] Regular review process established

## Key Principles

"The best metrics measure value delivery, not just activity." (Amplitude)

Focus on metrics you can act upon and improve.
