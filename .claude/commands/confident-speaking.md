# Confident Speaking

This skill helps structure presentations and pitches using Matt Abrahams' WHAT-SO WHAT-NOW WHAT framework.

## Core Framework

- **WHAT:** Present the core information
- **SO WHAT:** Explain why it matters
- **NOW WHAT:** Clarify next steps

## Key Presentation Structure

Effective talks follow this arc:
1. Hook (attention-grabber)
2. Problem (identify the issue)
3. Solution (your proposal)
4. Evidence (supporting data)
5. Call to Action (desired outcome)

## Core Insight

Abrahams emphasizes that "Structure sets you free. When you have a framework, you can focus on connecting, not remembering." This approach reduces anxiety by providing a reliable organizational backbone, allowing speakers to concentrate on audience engagement rather than recalling content.

## Best Practices

- Limit key points to three maximum
- Prepare examples and stories in advance
- Anticipate likely questions
- Use strategic pauses for emphasis
- Close with explicit next steps

## Use Cases

- Presentations
- Pitches
- Talking points
- Difficult conversations
