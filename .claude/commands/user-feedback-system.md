# User Feedback System

This skill helps implement structured feedback collection using two core methodologies.

## Key Frameworks

**Superhuman's PMF Survey** measures product-market fit through a single question: "How would you feel if you could no longer use [product]?" Success requires over 40% responding "very disappointed."

**YC's Talk to Users approach** emphasizes regular user engagement through:
- Weekly minimum conversations
- Open-ended questions
- Observational research focused on user jobs-to-be-done

## Implementation Components

The system includes:
- **In-app surveys** (PMF and NPS) with specific timing triggers
- **User interview cadence** with structured observation sessions
- **Feature request collection** across multiple channels
- **Weekly feedback review** with RICE-based prioritization

## Core Principle

As YC advises: "Talk to users. All the time. Until it feels like you're doing it too much." This underscores the importance of continuous, regular user engagement for building products that genuinely solve user problems.

## Key Takeaways

- Product-market fit is measurable through data, not intuition
- Close the feedback loop by communicating actions back to users
- Use RICE scoring to prioritize feature requests from feedback
