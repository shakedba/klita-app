# Workplace Navigation Guide

This resource helps you manage challenging interpersonal dynamics at work using evidence-based frameworks.

## Core Strategy

The approach centers on three key steps:
1. **Identify root causes** - Fear, goal misalignment, ego needs, or communication style differences typically drive difficult behavior
2. **Build shared ground** - Find mutual objectives that create collaboration opportunities
3. **Address directly** - Have a calm conversation focused on behavior, then escalate if necessary

## Key Insight

"Most difficult behavior stems from fear or misalignment, not malice."

This reframes how you interpret colleague actions, shifting from blame to understanding.

## Before Acting

- [ ] Examine what's actually driving the behavior
- [ ] Reflect on your own contribution to the dynamic
- [ ] Prepare a non-defensive opening question
- [ ] Identify what you both genuinely want

## When Conversations Fail

1. Document specific instances
2. Involve your manager
3. Establish clear boundaries
4. Protect your work priorities
