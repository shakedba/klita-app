# Zero to Launch: Idea → Prototype Playbook

## Overview

This playbook guides product development from concept to working prototype using three core frameworks:

1. **OpenAI's AI-First Thinking** (Kevin Weil): Build assuming models improve 10x every two months. Design for future capabilities while solving today's problems.

2. **Figma's Simplicity Forcing** (Dylan Field): Ruthlessly identify the ONE core job users need. Strip features until only essential value remains.

3. **Airbnb's Complete Experience** (Brian Chesky): Map entire user journeys before coding. Design all states (loading, error, empty, success) upfront.

## When to Use This Skill

Activate when users ask to build, prototype, or scope new features—especially for MVP planning or build-vs-buy decisions.

## Key Decision Framework

Before coding, verify:
- ✅ Core job defined (pass Figma simplicity test)
- ✅ AI opportunities identified (OpenAI lens applied)
- ✅ Complete experience mapped (Airbnb standard)
- ✅ Must-haves separated from nice-to-haves
- ✅ All user states designed

## Critical Insight

As Weil notes: "In two months, there's going to be a better model. If you're building on the edge of capabilities, keep going."

This means designing features that improve as underlying technology advances—particularly relevant for AI-powered products.
